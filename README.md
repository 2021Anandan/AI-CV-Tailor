# 📄 AI CV Tailor

An AI-powered resume optimization platform that tailors resumes to specific job descriptions using Artificial Intelligence, ATS keyword analysis, and Streamlit.

---

## 🚀 Features

- 📄 Upload Resume (PDF/DOCX)
- 💼 Paste Job Description
- 📊 ATS Compatibility Score
- 🎯 Keyword Matching
- ✍ AI Resume Optimization
- 📨 Cover Letter Generator
- 📧 Professional Email Generator
- 🎤 Interview Question Generator
- 📥 Export Resume (PDF & DOCX)

---

## 🛠 Tech Stack

- Python
- Streamlit
- Pandas
- PyMuPDF
- pdfplumber
- python-docx
- NLP
- Large Language Models (LLMs)

## ⚙ Installation

```bash
git clone https://github.com/2021Anandan/AI-CV-Tailor.git

cd AI-CV-Tailor

python -m venv .venv

.\.venv\Scripts\activate

pip install -r requirements.txt

streamlit run app.py
```
